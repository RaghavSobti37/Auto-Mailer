## Getting Started

### Prerequisites

- Git
- A runtime appropriate for the stack listed above

### Installation

```bash
git clone https://github.com/RaghavSobti37/Auto-Mailer.git
cd Auto-Mailer
npm install
```

### Development

```bash
npm run dev
```

### Production Build

```bash
npm run build
```
